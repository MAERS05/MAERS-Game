### Overall Impression

视觉基调温暖、触感扎实，实体卡纸与掌机卡槽的隐喻非常贴合多元独立游戏合集的气质；但 `<main>` 内部缺失垂直间距、`SQ-DU` 首屏双重重复渲染、筛选栏 `sq-du` 原始代号暴露以及说明书图标 `invert(1)` 反相，让页面在细节与信息架构上显得像尚未收尾的半成品。**最大的提升机会是将右侧 4 个静态品类色卡真正接入卡带数据与筛选体系，并修复 `<main>` 纵向呼吸感与首屏去重。**

### What's Working

1. **实体卡纸物理按压反馈体系 (`tokens.css:28-33`, `index.html:215-218, 405-413`)**：利用 `--shadow-stock` 与 `--shadow-primary` 的硬边阴影高度差（常态 `5px` → 悬停 `7px` → 按下 `1px` 配合 `translateY`），仅用纯 CSS 构建出富有游戏玩具感的按键触觉。
2. **世界观一致的空状态与降级态 (`index.html:680-729`)**：`buildUnknownCard()`（“卡槽 02 · 待装填品类”）与 `buildOfflineCard()`（“卡槽 01 · 离线状态 · 卡带柜未连接”）延续了实体卡带插槽叙事，避免生硬报错。
3. **等宽数字排版与减动效无障碍支持 (`index.html:105, 289, 346`, `base.css:25`)**：所有卡槽编号与统计数字均启用 `font-variant-numeric: tabular-nums`，且全局配置 `@media (prefers-reduced-motion: reduce)`。

### Priority Issues

- **[P1] What**: `<main id="mainContent">` (`index.html:516`) 缺失垂直布局间距，导致 `#featuredStage`、`.shelf-toolbar` 与 `#moduleGrid` 三大核心区块以 `0px` 间距紧贴粘连（`index-admin.html:705` 同理）。
  - **Why it matters**: 展台底边、筛选按钮与下方卡片顶边直接挤在一起，破坏了视觉分组边界与纸张排版的呼吸感。
  - **Fix**: 为 `main`（或 `#mainContent`）添加 `display: flex; flex-direction: column; gap: var(--space-xl);`。
  - **Suggested command**: `/impeccable layout`

- **[P1] What**: 单活跃游戏下 `#featuredStage` 与 `#moduleGrid` 100% 重复渲染 `SQ-DU` (`index.html:618-620`)，且展台标签硬编码为薄荷绿 `genre-chip--cozy` (`index.html:588`)。
  - **Why it matters**: 首屏 65% 面积展示完全相同的两张 `SQ-DU` 卡片，造成严重的视觉冗余；同时回合制战斗游戏挂着“治愈农业”绿标造成调性误导。
  - **Fix**: 当活跃卡带已在 `#featuredStage` 置顶展示且卡带总数较少时，在下方网格中过滤掉该置顶卡带（或将展台与网格差异化呈现）；根据卡带真实类型动态映射展台 `.genre-chip` 色卡。
  - **Suggested command**: `/impeccable distill`

- **[P1] What**: `.shelf-toolbar` (`index.html:520-530, 632-653`) 左侧筛选按钮直接显示底层目录代号 `sq-du`，右侧却并排放置 4 个不可点击的静态中文品类胶囊（`.genre-chips`）。
  - **Why it matters**: 新访客看不懂 `sq-du` 的含义，且极易误点右侧造型酷似按钮的“治愈农业 / 解谜推理 / 策略经营 / 战术对弈”胶囊（False Affordance），同一工具栏内 6 个胶囊并列也超出认知负荷阈值。
  - **Fix**: 建立 `gameType` 到中文名称及色卡的统一映射表（如 `sq-du` → `战术对弈`），将右侧静态 `.genre-chips` 合并进左侧 `#typeFilterNav` 作为真正的分类筛选器，或为每一张卡带动态着色。
  - **Suggested command**: `/impeccable clarify`

- **[P2] What**: `.manual-btn img` (`index.html:453` 及 `index-admin.html:285`) 残留暗色主题的 `filter: invert(1)`，将暖黄/深棕色的 `ui-all/guide-book.svg` 反相为刺眼的亮蓝 (`#0044ED`) 与浅青灰 (`#ABC1C1`)。
  - **Why it matters**: 反相后的浅青灰书页在暖白按钮背景 (`--color-paper`) 上对比度跌至 `1.65:1`，且亮蓝色块破坏了全站暖色卡纸视觉一致性。
  - **Fix**: 移除 `index.html:453` 与 `index-admin.html:285` 中的 `filter: invert(1);`。
  - **Suggested command**: `/impeccable polish`

- **[P2] What**: `BriefModal` (`manage/index/brief.js:11-27, 153-182`) 关闭状态下仅设置 `opacity: 0; pointer-events: none`，未移出键盘 Tab 序列，且打开/关闭弹窗时缺乏焦点移入与焦点归还。
  - **Why it matters**: 键盘与屏幕阅读器用户在页面底部按 Tab 会掉入不可见的隐藏弹窗内部（幽灵焦点陷阱），且打开说明书时焦点仍滞留在背景卡片上。
  - **Fix**: 在 `#maers-brief-overlay` 默认样式中添加 `visibility: hidden`（`.show` 时设为 `visibility: visible`），并在 `show()` / `hide()` 中管理焦点移入 `#maers-brief-close` 与归还至触发按钮。
  - **Suggested command**: `/impeccable harden`

### Minor Observations

- **大厅与工坊卡片点击热区不一致**：`index-admin.html:1267-1271` 支持点击整张卡片空白区域直接启动游戏，而 `index.html:269` 仅允许点击左下角 `.launch-btn` 启动。
- **字体远程加载阻塞风险**：`index.html:10` 依赖外网 `api.fontshare.com` 加载 `Chillax` 字体，离线或受限网络下会产生字体闪烁（FOUT）或请求超时。
- **`modules.json` 路径前导斜杠不一致**：`"url": "/games/..."` 使用根路径斜杠，而 `"cover": "games/..."` 使用相对路径，若部署在子目录（如 GitHub Pages）会导致游戏跳转 404。
